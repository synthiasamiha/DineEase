# DineEase

Restaurant Management and Online Ordering System

DineEase is a web application for a restaurant. Customers can browse the menu, order food online and reserve tables. The admin can manage the menu, orders, reservations and users from one dashboard.

## Features

- User registration and login (Customer and Admin roles)
- Menu browsing with categories and search
- Shopping cart and online ordering
- Order history
- Table reservation
- Contact form
- Admin dashboard (menu, orders, reservations, users)
